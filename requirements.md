# RecallDeck Requirements

## Version 1

- Create, edit, and delete flashcards.
- Store a front prompt and back answer.
- Review cards individually.
- Reveal or flip the current card.
- Mark a response by difficulty or correctness.
- Save cards and review state locally
- Schedule cards for later review
- Display cards due for review

## Interaction Experiments

- Custom-drawn flashcard.
- Hover feedback.
- Mouse dragging.
- Keyboard navigation
- Focus handling
- Card flip behavior

## Later

- Deck organization.
- Search and filtering.
- Import and export.
- Review statistict.
- More advanced spaced-repetition scheduling
- Optional visual themes
